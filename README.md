# Talos Assistants Community

This is the public home for questions, bug reports and ideas about
[Talos Assistants](https://talosassistants.com).

There is no code here. The product is built in private repositories. This repo exists so that
conversations about it happen somewhere public, where the answers stay findable.

## Where to go

| I want to... | Go to |
|---|---|
| Ask how to do something | [Discussions, Q&A](https://github.com/Talos-Assistants/community/discussions/categories/q-a) |
| Report something broken | [Open an issue](https://github.com/Talos-Assistants/community/issues/new/choose) |
| Ask for a specific feature | [Open an issue](https://github.com/Talos-Assistants/community/issues/new/choose) |
| Float a half-formed idea | [Discussions, Ideas](https://github.com/Talos-Assistants/community/discussions/categories/ideas) |
| Show what you built with it | [Discussions, Show and tell](https://github.com/Talos-Assistants/community/discussions/categories/show-and-tell) |
| Report a security vulnerability | Not here. See [SECURITY.md](SECURITY.md) |
| Send something privately | [talosassistants.com/feedback](https://talosassistants.com/feedback) |

Issues are for things that are broken, and for features specific enough to picture. Everything else
starts as a discussion. If a discussion turns out to be a real defect, we promote it to an issue and
link back.

## What Talos is

One self-hosted AI brain that you own, running on your own hardware, with every device as a channel
onto it. The Community edition is free and needs no account. Pro and Enterprise are not on sale yet.

- **Talos Brain** is the always-on service. This is the part you host.
- **Talos Studio** is the desktop app.
- **CLI** for scripting and automation.

Community is bring-your-own-key. The brain talks to whichever model provider you point it at, and
nothing needs to face the public internet.

## Before you post

- **Nothing has shipped yet.** The first Community release will be `1.0.0` and will appear on
  [the changelog](https://talosassistants.com/changelog) on the day it exists. If you are here early,
  Ideas is the most useful place to be.
- **[The guide](https://talosassistants.com/docs) is a tour, not a manual.** It walks through what
  Talos does in plain language. It contains no configuration and no reference material, and there is
  no configuration reference yet. Until there is, ask in Q&A. Those answers are what a reference
  eventually gets written from.
- **Search before opening**, both issues and discussions. Adding to an existing thread is worth more
  than starting a second one.

## Private feedback

You do not have to post in public. [talosassistants.com/feedback](https://talosassistants.com/feedback)
goes straight to us and needs no account. It exists for people whose install never started, who
therefore have nothing to report through. Anything sent there is read. It is just not visible to
anyone else.
